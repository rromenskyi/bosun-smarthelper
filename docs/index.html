Local-first AI assistant

An assistant that works when the internet doesn't.

Offline by default with its own local LLM, automatically prefers a remote model when online. Sensor tools, voice in and out, memo and document search, a local monitoring dashboard — all running on hardware you own, reachable over MCP from Claude Desktop or any MCP-compatible client.

What it does

Every one of these is real and running today, not a roadmap item.

🌐

Hybrid online/offline

A local model handles everything with no internet at all; a remote one steps in automatically when it's available, and steps back out the moment it fails.

🛰️

Real sensor tools

Weather (current + up to 16-day forecast, by place or exact coordinates), GPS, system status, fridge temperature — mock backends to start, real hardware when you have it.

📝

Memos, documents & maintenance tracking

Semantic search over personal notes and uploaded manuals via local embeddings, plus counter/date-based equipment upkeep tracking — an oil change and a boat's engine-hour meter fit the same two fields.

🎙️

Voice, both directions

Press-and-hold speech input and spoken replies, fully offline via whisper.cpp and Piper — no cloud STT/TTS, no Python in the path.

📊

Local monitoring dashboard

A bounded-history SQLite time series for CPU, memory, disk, GPS, fridge — a personal, config-driven analog to MRTG/Grafana with zero external dependency.

🔌

MCP-native

Every tool is exposed over the Model Context Protocol — point Claude Desktop or any MCP client at it and it's immediately usable there too.

How it's put together

One Go binary, plus two small local model servers docker compose builds and runs for you.

docker compose up ├── bosun the web UI + chat API + every tool (this repo) ├── llama-chat a local LLM (llama.cpp, built from source) ├── llama-embed a small local embeddings model, for memo/document search └── whisper-stt speech-to-text for the 🎤 button

Get started

The full, tested walkthrough is in INSTALL.md — this is the short version.

  1. Install Docker Engine + the Compose plugin (official docker.com repo).
  2. Clone the repo: git clone https://github.com/rromenskyi/bosun-smarthelper.git
  3. Copy the example configs: cp .env.example .env && cp configs/config.yaml.example config.yaml — no edits needed for a local-only test drive.
  4. Build and run: make docker-up
  5. Open http://localhost:8080
